# Backend - Sistema Web GLS

El backend del Sistema Web GLS se implementará en una etapa posterior.

El backend será responsable de:

- API REST
- autenticación
- autorización
- reglas de negocio
- validaciones del servidor
- comunicación con MySQL
- auditoría
- respaldo
- seguridad
- persistencia de información

En esta primera etapa únicamente se encuentra implementado el frontend.
